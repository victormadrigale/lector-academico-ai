# Política de costo cero

La aplicación debe poder usarse de forma indefinida sin suscripciones, API keys ni cobros por token.

## Permitido
- bibliotecas open-source compatibles;
- TTS incluido en Android/iOS;
- SQLite local;
- procesamiento local del documento;
- modelos locales opcionales con licencia compatible;
- compartir texto hacia ChatGPT u otra app instalada.

## No permitido como requisito
- OpenAI API;
- servicios TTS facturados por uso;
- OCR cloud de pago;
- base de datos cloud obligatoria;
- SDK PDF que requiera licencia comercial para el usuario objetivo;
- claves secretas incrustadas.

## ChatGPT
La aplicación no intenta reutilizar una suscripción de ChatGPT como API. Para aprovechar una cuenta personal se utiliza la app oficial mediante el flujo de compartir del sistema, que conserva la autenticación dentro de ChatGPT.
